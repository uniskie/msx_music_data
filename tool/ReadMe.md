# scc_edit (HTML)

SCC波形を編集するツール

https://uniskie.github.io/msx_music_data/tool/scc_edit.html

gemini3.5 Proによる生成をベースに調整。

音量問題対策で、手軽に振幅を変更する機能のついでに編集機能も。

元はテキストエディタ＋マクロで処理していましたがまとめた方が楽そうなので。

MGSDRV用のMMLファイルをドロップすれば適当にSCC波形定義を拾います。

htmlソースコード [scc_edit.html](scc_edit.html) (ダウンロードしてブラウザで開いて使用できます)
